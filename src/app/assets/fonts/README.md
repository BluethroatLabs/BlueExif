# Fonts

Self-hosted (no font CDNs — the CSP forbids third-party requests). Both are
licensed under the SIL Open Font License 1.1.

- `instrument-serif-latin.woff2` — Instrument Serif (Instrument), latin subset
- `geist-mono-latin.woff2` — Geist Mono (Vercel), latin subset, variable 100–900

These are the same subsets used across Bluethroat Labs tools (BlueMask, BlueSkills).
